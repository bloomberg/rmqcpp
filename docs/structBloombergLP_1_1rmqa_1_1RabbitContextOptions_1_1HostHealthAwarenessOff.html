Detailed Description

Tag type selecting an explicit opt-out from host health awareness; see setHostHealthSelection. Selecting it is distinct from leaving the host health selection unset (HostHealthAwarenessUnset), which expresses no preference and lets enclosing configuration layers apply their own policy.
