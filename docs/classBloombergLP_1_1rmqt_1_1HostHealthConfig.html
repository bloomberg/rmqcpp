Detailed Description

Class for passing arguments to HostHealthMonitor.

This class provides configuration for host health monitoring. When set via RabbitContextOptions::setHostHealthConfig, a HostHealthMonitor is created that periodically checks host health. Consumers with ConsumerConfig::consumeOnlyFromHealthyHost enabled (the default) will pause message delivery when the host is unhealthy and resume when healthy.

healthCheckerA function that returns true if the host is healthy, false if unhealthy. If the function throws, the check is retried up to maxRetriesOnFailure times before marking the host as unhealthy. This function runs on the main event loop thread and should complete promptly, as it will delay AMQP heartbeats and message delivery for all connections by its execution time every pollInterval seconds.
pollIntervalThe interval (in seconds) between each health check
maxRetriesOnFailureThe maximum number of retries on failure (exception) before marking host as unhealthy
