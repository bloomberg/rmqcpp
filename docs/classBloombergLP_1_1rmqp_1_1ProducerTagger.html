Detailed Description

A hook invoked by a producer once per send, to modify the message about to be published and to wrap its confirmation callback with state which must outlive the send. Distributed tracing is attached this way, by implementing rmqp::ProducerTracing.

One tagger is shared by every producer on a connection and is called concurrently, so implementations must be thread safe.
